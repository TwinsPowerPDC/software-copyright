# 软著申请表填写指南

本文档为中国软件著作权登记申请表的逐字段填写指南，基于《计算机软件著作权登记申请表》（中国版权保护中心）整理。

---

## 一、申请表字段总览

申请表字段分为两类：

| 类型 | 说明 |
|------|------|
| 模板内置值 | 已在 Word 模板中预填，填充脚本不替换，保持原文 |
| 需替换字段 | 模板中以 `{变量}` 标记，共 **6** 处，由 `fill_application_form.py` 按阶段三收集的内容替换 |

---

## 二、模板内置值字段

仓库内 `assets/application_form_template.doc` 在版权中心表体基础上，已将**开发完成日期**、**首次发表日期**两格改为 `{变量}`（与全称、简称等占位机制相同），由脚本写入，**不再**使用模板里的示例年月日。

下列字段仍为模板预填，填充脚本不替换（若公司信息变更，应在母版 `.doc` 中改好后重新入库，或按法务要求单独处理）：

| 字段名称 | 说明 |
|----------|------|
| 版本号 | 已填，通常为 1.0 |
| 软件作品说明 | 已填：原创 |
| 著作权人信息 | 已填，无需修改 |
| 运行平台/操作系统 | 已填，无需修改 |
| 编程语言、开发工具 | 已填，无需修改 |
| 权利取得方式、权利范围 | 已填：原始取得、全部权利 |

> **更换版权中心新母版时**：用 LibreOffice 将新 `.doc` 转为 `.docx` 后，运行 skill 内 `scripts/patch_template_dates_to_placeholders.py` 将两格固定日期改为 `{变量}`（与现有脚本、关键词匹配逻辑一致），再转回 `.doc` 覆盖 `assets/application_form_template.doc`。勿用 `textutil` 转换。

---

## 三、需替换字段（`{变量}` 占位符）

**模板格式**：申请表母版为 **`.doc`**（`assets/application_form_template.doc`）。填充前**必须**用 **LibreOffice**（`soffice --headless --convert-to docx`）或 Microsoft Word 另存为 `.docx`。**不要使用** macOS 自带的 `textutil -convert docx`：会把表格类 `.doc` 打成极简 OOXML，与原始模板版式完全不一致。

以下 **6** 个语义字段在模板中以 `{变量}` 标记（部分为 `{` / `变量` / `}` 分 run，由脚本统一处理），需由 `fill_application_form.py` 替换：

### 3.1 软件全称
- 格式：`[公司品牌][功能描述]软件/系统`，如 `影能科技智慧园区管理系统`
- 必须含公司品牌名，不含版本号（版本号在申请表其他字段中单独填写）
- 名称应与提交的设计文档、源代码文档保持一致

### 3.2 软件简称
- 3-10字，不得与全称完全相同，无简称可不填此位置（删除占位符留空）
- 示例：全称"XX企业资源管理系统 V1.0" → 简称"XX资管系统"

### 3.3 软件的主要功能
- 100-300字，按功能模块列点，强调"实现了什么"
- 参考格式：按 1/2/3 编号列出各模块功能描述

### 3.4 软件的技术特点
- 50-150字，列举3-5个技术亮点（架构、安全、性能、扩展性等）
- 参考格式：各特点用分号分隔，使用"采用XX技术实现XX效果"的句式

### 3.5 开发完成日期
- 格式须与在线/纸质申请表一致，常见为中文 `YYYY年M月D日`（与 `--dev-complete-date` 传入字符串一致即可）
- 须晚于**公司成立日期**，且不晚于填表当日；与事实相符

### 3.6 首次发表日期
- 格式同上（`--first-publish-date`）；须**不早于**开发完成日期
- 选择「未发表」或特殊口径时，由用户确认后**原样**传入脚本（不在成品 Word 中留「请核实」类字样）

## 四、提交材料清单

申请表提交时需附带（在线提交）：

| 材料 | 格式 | 说明 |
|------|------|------|
| 软件著作权登记申请表 | 在线填写 + 打印签章 | 中国版权保护中心官网填写 |
| 设计文档（软件说明书） | Word/PDF | 本 Skill 生成 |
| 源代码文档 | Word/PDF | 本 Skill 生成 |
| 申请人身份证明 | PDF | 营业执照副本（公司）或身份证（个人） |

**注意**：
- 申请通道：中国版权保护中心官网（www.ccopyright.com.cn）在线申请
- 普通申请：审核周期约 30 个工作日
- 加急申请：审核周期约 5-10 个工作日（需额外费用）
- 申请费用：以官网最新公告为准

## 五、常见审核退回原因及规避

| 退回原因 | 规避方法 |
|----------|---------|
| 软件名称含"平台"字样 | 改用"系统"、"工具"等词 |
| 日期逻辑错误 | 完成日期 < 发表日期，两者均晚于公司成立日期 |
| 简称与全称相同 | 确保简称有所省略或缩写 |
| 设计文档描述模糊 | 大量使用表格，字段说明要具体 |
| 源代码不足30页（前后各） | 确保前后各至少30页，内容真实 |
| 源代码与设计文档描述的功能不符 | 两份材料基于同一项目，保持一致 |
| 申请人信息与营业执照不符 | 公司全称与营业执照完全一致 |
