# 软著申请材料 · Cursor Skill

本仓库提供 **中国软件著作权登记** 相关流程的 Cursor Agent Skill：设计文档（软件说明书）、源代码 Word 汇编、申请表模板填充。

## 位置

| 内容 | 路径 |
|------|------|
| Skill 主文件 | `.cursor/skills/software-copyright/SKILL.md` |
| 写作/格式参考 | `.cursor/skills/software-copyright/references/` |
| 脚本 | `.cursor/skills/software-copyright/scripts/` |
| 申请表 `.doc` 模板 | `.cursor/skills/software-copyright/assets/application_form_template.doc` |

## 使用

1. 在 Cursor 中打开本仓库（或包含该 `.cursor/skills/` 目录的项目）。
2. 对话里 **`@software-copyright`** 加载 skill，按 `SKILL.md` 中的阶段执行；涉及脚本时先在终端 **`cd` 到** `.cursor/skills/software-copyright/` 再运行命令，或使用该目录下的绝对路径。

详细步骤、合规约束（零标注/零占位符等）以 `SKILL.md` 正文为准。
